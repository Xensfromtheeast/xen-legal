XEN privacy policy

Last updated: 19 October 2026

XEN is a personal app used only by its developer. It is not offered to other people.

Google user data

  • What XEN accesses: the developer's own Google Tasks (the Google Tasks scope), and nothing else from that Google account.
  • How it is used: to show their tasks in the XEN app and to let them add, complete or edit them.
  • Where it is kept: on the developer's own home server and devices. The sign-in token is stored on that server, readable only by the developer's user account.
  • Sharing: Google user data is not sold, not shared with third parties, not used for advertising, and not used to train AI models.
  • Removal: access can be revoked at any time at myaccount.google.com/permissions, which stops all access. Deleting the token file on the server removes the stored copy.

XEN's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
